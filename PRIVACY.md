# プライバシーポリシー (Privacy Policy)

**WoodStream PLAZA デスクトップクライアント**（以下、「本アプリ」といいます）におけるユーザー情報の取り扱いについて、以下の通りプライバシーポリシーを定めます。

制定日: 2026年9月19日  
開発・運営: WoodStream Networks Tomokazu Kizawa  

---

## 日本語 (Japanese)

### 1. 収集する情報および利用目的

本アプリは、ユーザーのプライバシーを尊重し、個人情報の保護に努めています。

- **個人情報の非収集**:  
  本アプリ自体は、ユーザーの氏名、住所、電話番号、位置情報などの個人を特定できる情報を収集・保存・外部送信することはありません。
- **アプリケーション設定情報**:  
  本アプリの利用環境を維持するため、以下の設定情報をユーザーの端末内（ローカルストレージ: `%LOCALAPPDATA%\WoodStreamPlaza\`）にのみ保存します。これらの情報が外部サーバーに送信されることは一切ありません。
  - ウィンドウの表示位置およびサイズ
  - タスクトレイ常駐設定
  - 表示言語設定（日本語 / 英語）
  - 通知設定（新着通知の有効・無効）
  - 起動時 URL 設定

### 2. Web コンテンツおよび認証情報の取り扱い

本アプリは、Microsoft WebView2 コントロールを利用してリスナーコミュニティ「[WoodStream PLAZA](https://windows-podcast.com/plaza/)」の Web ページを表示します。

- コミュニティ利用に伴うアカウント認証（Microsoft アカウント / Google アカウント等）や投稿内容、Cookie、セッション情報は、Web サービス「WoodStream PLAZA」および各認証プロバイダのセキュリティ基準とプライバシーポリシーに従って直接安全に送受信・管理されます。
- WebView2 が端末内に保持するキャッシュや Cookie などの一時データは、アプリ内の「設定」画面からいつでも消去することができます。

### 3. 第三者への情報提供

本アプリは、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供することはありません。

### 4. プライバシーポリシーの改定

本ポリシーは、法令の改正やアプリの機能更新等に伴い、予告なく改定されることがあります。重要な変更がある場合は、アプリ内またはリポジトリ上でお知らせします。

### 5. お問い合わせ窓口

本ポリシーに関するお問い合わせは、以下の GitHub リポジトリの Issue またはサポート窓口までお願いいたします。  
GitHub: [https://github.com/tkizawa/WoodStreamPLAZAApp](https://github.com/tkizawa/WoodStreamPLAZAApp)

## English

### 1. Information Collection and Use

**WoodStream PLAZA Desktop Client** ("the Application") is committed to protecting your privacy.

- **No Personal Data Collection**:  
  The Application itself does not collect, store, transmit, or sell any personally identifiable information (such as name, address, phone number, or geolocation data).
- **Application Settings**:  
  To maintain your user experience, the Application saves local settings strictly on your personal device (`%LOCALAPPDATA%\WoodStreamPlaza\`). These settings are never transmitted to external servers:
  - Window position and size
  - System tray minimization preferences
  - Display language preferences (Japanese / English)
  - Desktop notification preferences
  - Startup URL configuration

### 2. Web Content and Authentication

The Application utilizes the Microsoft Edge WebView2 runtime to display the "WoodStream PLAZA" community web content.

- Community interactions, user authentication (e.g., Microsoft Account, Google Account), cookies, and session data are handled directly between your client and WoodStream PLAZA / respective identity providers in accordance with their privacy policies.
- Local WebView2 cache, cookies, and temporary data can be cleared at any time via the Application Settings window.

### 3. Third-Party Disclosure

The Application does not share or sell any user information to third parties.

### 4. Contact Us

If you have any questions or feedback regarding this Privacy Policy, please reach out via GitHub Issues:  
GitHub: [https://github.com/tkizawa/WoodStreamPLAZAApp](https://github.com/tkizawa/WoodStreamPLAZAApp)
